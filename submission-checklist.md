- [ ] Final system prompt saved in `system-prompt.txt`.
- [ ] Prompt includes all seven eligibility checklist items.
- [ ] Prompt includes immediate disqualification rules.
- [ ] Prompt includes loan-transfer and EMI-reduction handling.
- [ ] Prompt includes the ₹75 lakh alternative-offer flow.
- [ ] Prompt includes busy-customer callback handling.
- [ ] Prompt includes out-of-order information extraction.
- [ ] Prompt includes interruption and diversion handling.
- [ ] Prompt includes all required assignment variables.

## B. Voice Platform

- [ ] Free trial or supported account configured.
- [ ] New voice agent created.
- [ ] System Prompt added to the agent instructions.
- [ ] Required variables mapped to actual platform features.
- [ ] Professional voice selected.
- [ ] Required language configured.
- [ ] Calling capability configured if required by the platform.
- [ ] Test calling and recording permissions checked.

- [ ] Busy-customer callback flow tested.
- [ ] Out-of-order answers tested.

## D. Recording Evidence

- [ ] Actual call recordings collected.
- [ ] Audio transcripts collected.
- [ ] Recording links associated with the correct test scenarios.
- [ ] Public or evaluator-accessible link prepared.
- [ ] Sharing permissions verified using an appropriate test.
- [ ] No unnecessary personal or sensitive customer information exposed.

## E. Final Submission

Required by the assignment:

- [ ] System Prompt text.
- [ ] Public link to call recordings and call logs, including audio and transcripts.

Optional supporting material:

- [ ] Brief explanation of the implementation approach.
- [ ] Test summary.
- [ ] Known limitations, if any.

## Final Verification

Do not submit fabricated test results, placeholder links, or claims that the agent works without testing it.

Confirm that the prompt has been configured on the voice platform and that the shared recordings and transcripts are accessible to the evaluator.
